# النمط البصري — CleanShot X (استخلاص من التوثيق العام)

ملاحظات عن **كيف يبدو** المنتج وما الذي يجعله «نظيفاً»، مستخلصة من لغة التسويق والوصف
الرسمي. لا أصول ولا هوية مُنسوخة.

## 1. النظافة (Cleanliness)

- الوعد المحوري حرفياً: *"Take clean, presentation-ready screenshots in seconds"* —
  النظافة ليست زينة بل **وعد وظيفي**: الصورة جاهزة للعرض بلا تجهيز إضافي.
- استمرار بلا انقطاع: *"No folders to dig through, **no flow to break**"* — النظافة
  تُقاس بغياب الانقطاع، لا بعدد العناصر الجميلة.
- مقابل صريح ضد «التطبيق المتوسّط»: *"There are average capture apps. And there's CleanShot."*
  → الإبهار محظور، والمقياس هو التنفيذ والدقة.
- وعود قصيرة محدّدة لا صفات مبهمة: «مسار سريع»، «ضغط زر واحد»، «رابط جاهز فوراً».

**المبدأ:** واجهة نظيفة = نص أقل، حدود أقل، قرار واحد واضح لكل شاشة.

## 2. الأسطح الهادئة (Calm Surfaces)

- الواجهة تصف نفسها: *"The interface is simple, with great, native performance"* +
  *"Native macOS look and feel"* و *"Modern interface with perfect UX"*.
- الأسطح **تختفي لصالح المحتوى**: التدفق كله يبدأ من «التقاط شيء» ثم النتيجة أمامك
  مباشرة — الواجهة ليست البطل، بل الصورة المُلتقطة هي البطل.
- وضعا فاتح وداكن مدعومان كخيار متساوٍ (`Dark and Light mode support`)، لا وضع داكن
  مباع كميزة.
- انضباط في التخصيص: المستخدم يضبط «الاختصارات، سلوك الالتقاط، الصيغ، خيارات المشاركة»
  في مكان واحد مهيّأ، لا مبعثر.

**المبدأ:** الأسطح تحمل المحتوى ولا تتنافس معه؛ والتخصيص مُجمَّع ومهيّأ لا مبعثَر.

## 3. الأدوات المدمجة (Embedded Tools)

- لا مغادرة للتطبيق هي قاعدة متكرّرة: *"without leaving the app"* / *"built right into
  CleanShot"* / *"all without leaving CleanShot"*. المحرّر والمقياس والإطار والمشاركة
  كلها **داخل** الرحلة نفسها.
- التفاعل يظهر **عند الحاجة فقط**: **Quick Access Overlay** — «لقطة صغيرة في الزاوية
  فور التقاطها» للعرض أو التعليق أو المشاركة، مع إمكانية الإخفاء والاسترجاع وضبط
  الموضع والحجم وسلوك الإغلاق التلقائي.
- **Drag & Drop كفعل أساسي**: زر «Drag me»، سحب الملفات إلى أي تطبيق، دمج عدة لقطات
  بسحب لقطة أخرى داخل نافذة التعليق.
- الاستمرارية بين الجلسات: **Capture History** يحفظ شهراً كاملاً ويسترجِع بلمسة، و
  **CleanShot file format** يحفظ التعليقات كملف مشروع قابل للتحرير لاحقاً.

**المبدأ:** الأدوات تعيش داخل المسار لا في شاشات منفصلة، وتظهر عند الطلب لا قبله.

## 4. العمق الخفيف (Light Depth)

- طبقات منخفضة الارتفاع، لا نافذة مثبّتة دائمة: الـ Overlay «صغير في الزاوية» قابل
  للضبط والإخفاء؛ المحتوى يطفو فوق المحتوى فقط عند فعل محدّد.
- **Floating Screenshots**: مصوَّر كـ «مرجع يبقى مرئياً فوق كل النوافذ» مع ضبط
  *الحجم والشفافية* والموضع بالأسهم، و**Lock Mode** للتفاعل مع ما تحته → العمق أداة
  وظيفية (مرجعية) لا حشوة.
- الحركة وظيفية لا احتفالية: **Smart zooms** تتبع المؤشر لتوجيه الانتباه، **click
  highlights** و**keystrokes** لتوضيح الفعل، **motion blur** «طبيعي» قابل للضبط —
  كل حركة تشرح شيئاً.
- مقياس التباين كوعد صريح: يُذكر أن أي ميزة تُوصف بـ *fast and private by design*
  (OCR على الجهاز) → الخصوصية جزء من «الاسترسال» لا إعداد مخفي.

**المبدأ:** ارتفاع منخفض وشفافية قابلة للضبط، والحركة تشرح ولا تُسلّط.

## ما لا يُنقل إلى خيال

| عنصر في CleanShot | سبب عدم النقل |
|---|---|
| أزرق `#0d44e8` لون العلامة | لون CleanShot — خيال يحتفظ بـ **`#CC1728`** |
| الشعار وصور الشهادات وشعارات الشركات | **أصول وعلامة** — ممنوع النسخ |
| نبرة «التطبيق الأفضل على Mac» | خاصة بمنتج ماك أصلي؛ خيال منصة عربية متعددة المنصات |
| التسجيل بالمخطط وضغطات لوحة المفاتيح | وظائف ماك مادية، لا مقابل لها في خيال |

## المبادئ الأربعة المُستخلصة (خلاصة)

1. **النظافة** = وعد وظيفي، نص قصير، قرار واحد لكل شاشة، لا انقطاع.
2. **الأسطح الهادئة** = المحتوى بطل، الواجهة خلفية، التخصيص مجمّع.
3. **الأدوات المدمجة** = داخل المسار، تظهر عند الطلب، سحب وإفلات، استمرارية بين الجلسات.
4. **العمق الخفيف** = ارتفاع منخفض، شفافية قابلة للضبط، حركة تشرح.
