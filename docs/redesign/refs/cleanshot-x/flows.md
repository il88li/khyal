# التدفقات ورحلة الإتمام — CleanShot X (توثيق عام)

ما يصفه التوثيق عن **تسلسل** الأفعال من البداية إلى الإتمام. هذه أهم طبقة لخيال، لأن
مشكلة خيال الحالية احتمالها في التسلسل لا في اللون.

## التدفق 1 — الالتقاط ثم المشاركة («Always one drag away»)

```
اختصار واحد → اختيار وضع الالتقاط → ضبط الإطار/الأبعاد → التقاط
   → Overlay فوري في الزاوية → حفظ/نسخ/سحب/تعليق/رفع → رابط جاهز
```

- **نقطة الدخول:** اختصار واحد يفتح كل الأوضاع (All-In-One) ويحفظ آخر تحديد.
- **صفر شاشات وسيطة تُطلب:** «Save it, copy it, or drop it straight into any app.»
- **حالة الإتمام:** ملف/رابط **جاهز للمشاركة**، لا «تم الحفظ في مجلد».
- **فروق المسارين:** التقاط للمشاركة السريعة vs التقاط للتعليق والتجهيز.

## التدفق 2 — التعليق والتجهيز (Annotate → Share)

```
فتح المحرّر من الـ Overlay → إضافة (سهم/نص/عدّاد/تظليل/طمس)
   → تجهيز (خلفية/حشوة/قص/إطار) → تصدير بالصيغة المطلوبة
```

- **الأدوات داخل المسار:** «all without leaving CleanShot».
- **الحفظ قابل للاسترجاع:** ملف مشروع قابل للتحرير لاحقاً → «لا حاجة لإتقان التعليق من
  المحاولة الأولى» (تقليل ضغط الإتمام المثالي).
- **العدد مقيّد بالحاجة:** 4 أنماط سهم، 7 أنماط نص، 20 خلفية — **كافٍ ومحدود**، لا مكتبة
  لا نهائية تُربك.

## التدفق 3 — التسجيل ثم النشر

```
تسجيل سريع (شاشة/كاميرا/صوت) → إن احتجت: Studio Mode
   → تقليم + تكبير تلقائي + تنعيم مؤشر + خلفية → تصدير لمنصة (عمودي/مربّع/أفقي) → مشاركة
```

- **مسار متدرّج:** الفعل السريع ينجح وحده، والتحسين **اختياري** لا شرط للنجاح.
- **تصدير موجَّه للمقصد:** «ready for TikTok, Instagram Reels, YouTube» — المخرَج يبدأ
  من الوجهة لا من الصيغة.

## التدفق 4 — المشاركة والتعاون (Cloud)

```
رفع بضغطة من الـ Overlay → رابط نظيف → مشاركة
   → تعليقات على الصورة/بالتوقيت على الفيديو → (اختياري) انتهاء صلاحية/كلمة مرور/SSO
```

- **الرفع ليس شاشة منفصلة** بل فعل من الـ Overlay.
- **التحكم بعد المشاركة:** انتهاء صلاحية، حماية بكلمة، تدمير ذاتي — أمان بقدر الحاجة.

## استدارة الجولة كلها (ما يحافظ على العودة)

| لحظة | ما يعيد المستخدم |
|---|---|
| Capture History | «لا تعِد أي لقطة» — يسترجع من شهر |
| CleanShot format | العمل غير المكتمل يبقى قابلاً للتعديل |
| Overlay قابل للاسترجاع | لا تفقد ما أغلقت |
| Pin / Floating | المرجع يبقى أمامك أثناء المقارنة |
| التخصيص المحفوظ (presets) | كل لقطة تالية أسرع |

## دروس التسلسل لخيال

1. **الفعل الأساسي ينجح وحده**؛ التحسين خطوة **اختيارية** لا بوابة.
2. **نقطة دخول واحدة** لكل شيء (All-In-One) مع حفظ آخر اختيار.
3. **حالة إتمام محسوسة** (رابط/نتيجة جاهزة) لا «تم الحفظ».
4. **الأدوات الفرعية داخل المسار**؛ لا شاشات منفصلة تُطلب.
5. **الاستمرارية** (سجل + ملف قابل للاسترجاع) تقلّل ضغط «الإتمام المثالي».
6. **التصدير يبدأ من الوجهة** لا من الصيغة.
