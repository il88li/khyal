# الشاشات وأنماط الواجهة — CleanShot X (توثيق عام)

جردة الشاشات كما هي موثّقة علناً، مع **النمط الواجهوي** الذي تجسّده كل واحدة.
لا لقطات، لا أصول.

## الشاشة الرئيسية (Home / Product)

- بنية ثابتة: عنوان ووعد → **زر إجراء واحد مهيمن** + رابط ثانوي «How it works» →
  دليل ضمان (30-Day Money-Back) → إثبات اجتماعي (شهادات + شعارات شركات) → قسم لكل
  قدرة → دعوة أخيرة.
- عنوان الصفحة الأولى مقارنة صريحة لا وصف: *"There are average capture apps.
  And there's CleanShot."* → موضع واحد واضح في السوق.
- **الاعتماد على صور منتج حقيقية** لشرح كل قدرة (لقطات الواجهة نفسها هي المحتوى)، لا
  رسومات زخرفية.

## شاشة «الشاشات» (Screenshots)

- عنوان وعد معلَني *+* سطر تفسيري واحد: «التقاط، تعليق، إخفاء، مشاركة دون إبطائك».
- **مجموعات قصيرة متساوية** لكل قدرة: عنوان قصير + 3–4 نقاط. لا فقرات.
- تمييز لمسار القوة الخمسة: Highlight / Redact / Background / Crop / CleanShot format.
- إغلاق بدعوة واحدة + إعادة تأكيد الضمان.

## شاشة «التسجيل» (Screen Recording)

- **تقسيم بمشهد ثابت**: «تسجيل سريع في ثوانٍ…» مقابل «عرض مصقول في Studio Mode» →
  خياران مكاينان للمسارين (سريع / احترافي) في شاشة واحدة، بلا خيار ثالث مشوّش.
- ثم شبكة ميزات متساوية العرض، ثم **مقارنة رقمية واحدة** (2x أسرع) لا جدول طويل.

## شاشة «كل الميزات» (Features)

- **فهرس أقسام قابل للقفز**: Annotate · Background · Quick Access Overlay · Screenshots ·
  Recording · Editor · Cloud · Floating · OCR · All-In-One · History · Settings.
- داخل كل قسم: **قائمة نقاط عميقة** (7 أنماط سهم، 7 أنماط نص…) → الكثافة هنا مقبول لأن
  المستخدم جاء يبحث، لا يتأمّل.
- كل ميزة تنضج على أسطر: *«العنوان الميزات: Native look · Modern UX · Performance ·
  Sharing · Drag me · Dark/Light»*.

## شاشة الإعدادات (Settings)

- التخصيص كقسم كامل ومعلن: اختصارات، سلوك الالتقاط، الصيغ، المشاركة، حجم/موضع
  الطبقات، سلوك الإغلاق التلقائي، دعم الشاشات المتعددة.
- **الافتراضي جيد، والخيارات متاحة** — لا شيء مفروض.

## أنماط تتجاوز الشاشة الواحدة

| النمط | الوصف |
|---|---|
| Overlay فوري | ظهور صغير في الزاوية بعد الفعل مباشرة، قابل للضبط والإخفاء والاسترجاع |
| جدل إجراءات سريع | حفظ / نسخ / سحب / رفع — أربعة مخرجات متساوية البعد |
| انتقال بلا كسر | «No flow to break»: من الالتقاط إلى الرابط دون شاشة وسيطة تُطلب |
| مخرجات متعددة | MP4 ↔ GIF، عمودي/مربّع/أفقي لكل منصة، صيغ تصدير محددة |
| إثبات بالمنتج | كل قدرة تُشرح بلقطة من الواجهة نفسها |

## ما يُستفاد منه لخيال

1. كل شاشة = وعد + سطر تفسيري + مسار واحد.
2. قدرات متساوية العرض بعناوين قصيرة و٣ نقاط، لا فقرات.
3. مساران (سريع/احترافي) معلنان بدل خيار ثالث مربك.
4. الإعدادات قسم واحد مجمّع ومقروء.
5. الفهرس القابل للقفز لصفحات القدرات الطويلة.
